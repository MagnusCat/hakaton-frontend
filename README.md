# hakaton-frontend

Фронтенд клиники на ванильном JS . Данные захардкожены в `js/data.js`, доступ к ним — через mock-слой `js/api.js` (Promise с задержкой, готов к замене на `fetch`).

## Структура

```
index.html          — логин + каркас SPA (навигация, контейнер представлений)
css/styles.css      — стили
js/data.js          — window.DB: врачи, специальности, пользователи, дни недели
js/api.js           — window.API: mock-API (login, getDoctors, getScheduleByDate,
                      getSpecialties, getUsers, checkTimesUnique)
js/app.js           — состояние, роутинг по вкладкам, авторизация, рендер разделов
```

## Разделы

1. **Авторизация** — вход через `API.login(login, password)`, роли: `пользователь`, `администратор`.
2. **Календарь** (главная) — месячная сетка с расписанием врачей, клик по дню показывает приёмы (время, ФИО, специальность).
3. **Сотрудники** — таблица: ФИО, специальность врача, время приёма (уникально в течение недели, проверка — `checkTimesUnique`).
4. **Специальности** — список специальностей и напротив каждой список лечимых заболеваний.
5. **Пользователи** — логин, пароль, роль; доступно только администратору.

## Демо-доступ

| Логин    | Пароль      | Роль            |
|----------|-------------|-----------------|
| admin    | admin123    | администратор   |
| manager  | manager456  | администратор   |
| doctor1  | doctor123   | пользователь    |
| patient  | patient123  | пользователь    |



## Замена mock-API на реальный бэкенд

Все запросы идут через `window.API` (`js/api.js`). Достаточно заменить тела методов на `fetch(\`${BASE_URL}/...\`)`.
