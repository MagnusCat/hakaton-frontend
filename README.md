# hakaton-frontend

Фронтенд клиники на ванильном JS. Работает с реальным бэкендом через `fetch` (`js/api.js`).
Авторизация — JWT (`Authorization: Bearer`), токен хранится в `localStorage`.

## Структура

```
index.html          — вход/регистрация + каркас SPA (навигация, контейнер представлений)
css/styles.css      — стили
js/api.js           — window.API: обёртка над REST-бэкендом (auth, doctors, schedule,
                      specialties, users, appointments, slots, employees)
js/app.js           — состояние, роутинг по вкладкам, авторизация, рендер разделов
```

## Разделы

1. **Авторизация** — вход (`POST /api/auth/login`) и регистрация пациента
   (`POST /api/auth/register`). Роли: `ADMIN` / `PATIENT`.
2. **Календарь** (главная) — месячная сетка с расписанием врачей, клик по дню показывает приёмы.
3. **Записи** — пациент видит и создаёт свои записи, админ видит все; отмена записи.
4. **Сотрудники** — ФИО, специальность, время приёма, ближайший приём.
5. **Специальности** — специальности и лечимые заболевания.
6. **Пользователи** — логин, пароль, роль; только для администратора.

## Демо-доступ

| Логин | Пароль   | Роль          |
|-------|----------|---------------|
| admin | admin123 | администратор |

Пациенты регистрируются сами через форму «Зарегистрироваться как пациент».

## Адрес бэкенда

`js/api.js`: `const BASE_URL = "http://159.194.246.91:8090/api"`.
Для локальной разработки замените на `http://localhost:8080/api` или относительный `/api`
(если фронт раздаётся через reverse-proxy рядом с бэком).
